# 杭州 · 智能平民宇宙设定

> 本文档汇总「平民宇宙」中**杭州全境地图**的现实底稿、50 年（至 2076）未来推演、与现实空间的平行映射 schema，以及驱动地图自动刷新与状态同步的定时任务机制。
> 配套代码：`src/content/scenes/hangzhou_hub.js` + `hz_*.js`（13 区县）、`tools/hangzhou/evolve.mjs`（演化引擎）、`src/content/scenes/hangzhou.state.js`（动态状态）、`HANGZHOU_STATUS.md`（城市脉搏报告）。

## 三、平行映射 schema（虚拟 ↔ 现实 一一对应）

每个杭州场景在 `schema.md` 基础上扩展三个**可选字段**，使虚拟场景与现实空间锚定：

```js
geo:  { lat, lng, areaKm2, realPop, realGdp, anchorsReal[] }  // 真实质心经纬度与锚点
real: { pop, gdp, summary }                                    // 现实底稿
future: { year: 2076, vision, anchors[], tags[] }              // 设定年推演
```

**星图投影**（见 `hangzhou_hub.js`）：把 13 区县的真实经纬度线性投影到 16×16 的星图平面——
- `x = (lng − 119.05) / 1.37 × 16 − 8`
- `z = −(lat − 29.48) / 0.94 × 16 + 8`（北在远处 −z）

每个区县在星图上是一支**光柱信标**：高度随常住人口缩放、颜色区分、顶端发光球为数字孪生节点。玩家从场景菜单进入任一区县，即可在镜像里深度探索。

> 引擎只消费 `id/name/sky/ground/fog/spawn/props/spots/meta`；`geo/real/future` 仅作数据沉淀与工具消费，不影响渲染。

## 四、定时任务机制（驱动地图自动刷新与状态同步）

### 1. 触发周期
- **周期**：每日一次（默认 **03:00**，RRULE `FREQ=DAILY;BYHOUR=3;BYMINUTE=0`）。
- 每次推进 **+2 模拟年**；从 2026 到 2076 约 **25 天**走完，之后封顶、城市保持「活着」的波动。
- 如需更快/更慢，改 `--step` 或周期即可；也可复制一份做成「每 6 小时」的实时心跳。

### 2. 执行内容（`tools/hangzhou/evolve.mjs`）
1. 读取 `hangzhou.state.js` 的 `HZ_STATE`（首跑自动按 2026 基线初始化）。
2. 推进模拟时钟 `simYear += step`。
3. **人口**：13 区县按线性插值从 2026 现实值逼近 2076 目标，叠加轻微噪声。
4. **繁荣/能量/情绪**：有界随机游走（0~100），模拟镜像宇宙自组织波动。
5. **phase**：全城统一昼夜相位推进，让镜像昼夜与现实平行。
6. **事件流**：每轮随机生成 1~2 条「城市事件」写入 `feed`（滚动保留最近 20 条）。
7. 写回 `hangzhou.state.js` 与 `HANGZHOU_STATUS.md`（人类可读「城市脉搏」）。

### 3. 更新逻辑（幂等、安全、可回滚）
- 工具**全量重写**状态文件（非增量 patch），天然幂等；`--init` 可一键回滚到 2026 基线。
- 只写两个**机器生成**文件，绝不触碰人工创作的场景文件，无回归风险。
- 到达 2076 后 `simYear` 封顶，但波动继续，城市不会「停摆」。

### 4. 状态同步（自动刷新如何驱动地图）
- 游戏运行时读取 `HZ_STATE`：把 `pop` 映射到星图光柱高度、`prosperity` 映射中枢亮度、`feed` 映射全息屏滚动文案——**定时任务改状态文件 → 引擎下次加载即呈现最新脉搏**，这就是「地图数据自动刷新 → 状态同步」。
- 仓库侧：自动化把状态文件 **commit + push 到 main**（仅这两个文件），使云端镜像与本地/运行实例始终一致；社区合并即完成一次全局同步。
- 与人类创作的场景（PR 评审制）不同，状态层走**直推 main** 的快速通道——因为它是低风险的生成态，且必须「实时」才体现同步价值，每次提交都可在历史中回看城市演化轨迹。

### 5. 与「创始神」的关系
- **创始神**（`god/map-*`）：向外**扩张世界边界**（新增地块），走 PR 评审。
- **杭州心跳**（本任务）：向内**深化既有世界**（让已建好的杭州持续演化），走直推同步。
- 二者互补：一个负责「长」，一个负责「活」。

## 五、如何体验与扩展
- 本地 `npm run dev` → 场景菜单选 **「杭州总览 · 平民宇宙星图」** 看 13 区县星图，再选任一 `hz_*` 区县深入。
- `npm run hz:init` 重置基线；`npm run hz:evolve -- --step N` 手动推进。
- 扩区/改推演：编辑对应 `hz_*.js` 的 `future` 字段（纯数据，引擎零改动）；改演化规则：`tools/hangzhou/evolve.mjs` 的 `MODEL` 与 `advance()`。
